# 🚴 GhostPace — GPS 사이클링 레이스 (데모)

**같은 코스 위에서 고스트·AI 라이더와 실시간으로 순위를 다투는 라이딩 경쟁 게임 — 앞 라이더를 추격하고, 뒤 라이더를 따돌리며 랭크를 올리세요.**

브라우저 안에서 완전히 동작하는 "혼자서 고스트와 대결하는" 사이클링 레이스 시뮬레이터입니다. 코스를 고르고, 내 속도를 조절하고, 내 라이더와 여러 결정론적 고스트/AI 라이더가 트랙 위에서 실시간으로 움직이는 것을 보며, 추격·도주로 포인트를 얻고, 베스트 타임을 코스 리더보드에 저장하고, 내 기록 고스트와 다시 대결할 수 있습니다.

## 무엇인가

야외 라이딩 경쟁을 게임으로 옮긴 것입니다. 실제 제품이라면 같은 코스를 달리는 다른 라이더의 *실제* GPS 위치를 보며 경쟁하겠지만, 이 데모는 서버·계정·실제 GPS 없이 그 **감각과 메커니즘**을 진짜 물리 기반 레이스 시뮬레이션으로 구현합니다.

## 레이스 시뮬레이션 원리

애니메이션 스크립트가 아니라 **틱 기반 실제 시뮬레이션**입니다.

- **코스** = 코스의 `shapeSeed`로부터 결정론적으로 생성되는 인라인 SVG 순환 트랙(`render.js`의 `trackPathD`). 라이더는 거리 비율에 따라 브라우저 `getPointAtLength`로 트랙 위에 배치됩니다.
- **내 라이더**는 **내가 조절하는 속도**(km/h 슬라이더 또는 🤖 오토페이스)로 전진합니다. 매 틱: `거리 += 속도(m/s) × dt`.
- **고스트/AI 라이더**는 **문서화된 페이스 커브**(`ghostSpeedAt`)로 전진합니다: 기본 순항속도 × 현재 구간 난이도 계수(오르막 `< 1`, 평지/내리막 `≥ 1`) × 라이더별 `grit`(오르막에서 페이스를 얼마나 버티는가) + 50m 단위의 작은 결정론적 노력 변동.
- 매 틱마다 엔진이 **순위를 계산**합니다 — 모든 라이더를 거리순 정렬해 랭크를 매기고, 바로 **앞/뒤 라이더와의 간격**(미터 + 예상 초)을 계산합니다.
- 루프는 `app.js`에서 **`requestAnimationFrame`**으로 구동되며, 탭 전환 시 순간이동을 막기 위해 `dt`를 제한합니다.
- **결정론적:** 같은 `seed` + 같은 속도 시퀀스 + 같은 `dt` 시퀀스 → 완전히 동일한 위치. 그래서 **고스트 리플레이가 그대로 재현**되며, 이는 `check.mjs`의 단위 테스트로 검증됩니다.

계산은 **`race-engine.js`**(순수, DOM 없음), 그리기는 **`render.js`**, 오케스트레이션·UI·저장은 **`app.js`**에 있습니다.

## 기능

- 🗺️ **코스 6개** — 한강 라이트 루프, 강변북로 스프린트, 남산 힐클라임, 올림픽 벨로드롬, 북한강 롱라이드, 해안도로 크리테리움 (거리·난이도·지형·구간 프로필).
- 🏁 **레이스 화면** — 내 라이더 + 여러 고스트/AI 라이더가 트랙 위를 실시간 이동, 실시간 순위·속도·경과시간·거리·**앞/뒤 라이더 간격**.
- 🎮 **게임 요소** — **추격 성공**(추월) / **도주 성공**(결정적 간격 벌리기) 보상 포인트, 완주·순위 보너스, 랭크 티어 Bronze → Legend.
- 🏆 **기록·리더보드** — 코스별 베스트타임 + 코스 리더보드(내 베스트 vs 결정론적 필드).
- 👻 **고스트 리플레이** — 내 베스트 주행을 녹화해 "내 고스트" 라이더로 다시 대결.
- 👤 **프로필** — 레벨·포인트·티어·배지·코스별 베스트.
- ➕ **추가 요소** — 스플릿 구간 난이도 프로필, **심박·케이던스 mock** 표시, **웨어러블 음성 알림 예시 문구**("추월 성공! 다음 라이더까지 밀어붙이세요.").
- 🌗 라이트+다크 테마, 모바일 우선 반응형, 스포티한 한국어 UI.

## 로컬 실행

빌드 없음. 정적 서버면 됩니다(ES 모듈·`fetch`는 `file://`이 아니라 `http://` 필요).

```bash
# 저장소 루트에서
python -m http.server 8993
# http://localhost:8993 접속
```

이후: **코스 선택 → 출발 → 속도 조절 → 추격/도주 → 완주 → 베스트 저장 → 고스트 리플레이.**

## 🟨 데모 모드 경계 (꼭 읽어주세요)

**이것은 데모입니다. 실제 GPS 멀티플레이어 제품이 아니라 시뮬레이션입니다.** 구체적으로:

- **고스트/AI 라이더는 개략적 코스 위의 시뮬레이션이며 — 실제 사람도, 실제 GPS도 아닙니다.** 트랙은 실제 지도 경로가 아니라 양식화된 루프입니다.
- **고스트 페이스는 시드 데이터 + 결정론적 커브**에서 나오며, 실제 주행 기록이 아닙니다.
- **기록·포인트·베스트타임은 `localStorage`에만 저장 — 진짜 데이터베이스가 아닙니다.** 브라우저 하나에만 남고, 지워질 수 있으며, 동기화되지 않습니다.
- **계정도 PII도 없습니다.** 아무것도 업로드되지 않습니다. 브라우저 Geolocation은 사용하지 않습니다(실제 빌드라면 선택적·명시적으로 사용).
- **실제 프로덕션 빌드라면 추가될 것:** 실제 GPS 추적, 라이브 멀티플레이어 넷코드(다른 라이더의 실제 위치), 인증 계정, 서버 사이드 안티치트, 실제 리더보드 DB.

모든 라이더 이름·코스·리더보드 항목은 **가상의 데모 데이터**입니다.

## 기술

- 순수 **HTML + CSS + ES 모듈 JavaScript**, 상대 경로, **빌드/의존성 없음**.
- 트랙·라이더 = **인라인 SVG**. 루프 = `requestAnimationFrame`.
- `race-engine.js`(시뮬 계산) · `render.js`(그리기) · `app.js`(앱) · `data/courses.json`(코스·고스트 데이터).
- **CI:** `node check.mjs` — JSON 검증, 전 JS `node --check`, `index.html` 필수 컨테이너 확인, 그리고 **`race-engine.js` 단위 테스트**(위치·간격·순위·완주·점수·결정론) 40+ 검증.

## 🤖 AI 기능 (API 연동)

GhostPace에는 **안전하고 교체 가능한 AI 레이어**가 포함되어 있으며, 세 가지 기능을 제공합니다:

1. **AI 라이딩 코치 챗봇** (레이스 화면) — 선택한 코스의 구간 프로필과 내 베스트·티어를
   근거로 페이싱·훈련 조언을 하고, 레이스 중에는 실시간 간격 코칭도 제공합니다.
2. **레이스 결과 분석/코멘터리** (결과 화면) — 완주한 레이스의 스플릿·최종 순위·간격·
   포인트 내역을 바탕으로 중계를 생성합니다.
3. **코스 추천** (코스 선택 화면) — 목표와 레벨에 맞는 코스를 추천합니다.

**데모 = mock (기본값).** `ai/config.js` → `AI_ENDPOINT = ""` 상태에서는 세 기능 모두
앱의 코스·레이스·베스트 데이터로 구동되는 **결정론적 한국어 MockProvider**(`ai/ai.js`)로
동작합니다. 네트워크·계정·키가 필요 없습니다.

**실 Claude 연동**은 [`server/`](server/) 백엔드 프록시로 켭니다:

```bash
cd server
cp .env.example .env      # .env에 키를 붙여넣기
npm install && npm run start:env
```

그 다음 `ai/config.js` → `AI_ENDPOINT = "http://localhost:8787/api/ai"`로 설정하고
새로고침하세요. 프록시가 Claude(모델 **`claude-opus-5`**, adaptive thinking, 스트리밍)를
호출해 응답을 토큰 단위로 되돌려줍니다.

> **🔒 키는 서버 사이드에만 둡니다.** `ANTHROPIC_API_KEY`는 오직 `server/.env`
> (`process.env.ANTHROPIC_API_KEY`)에만 존재하며, 브라우저·`ai/config.js`·저장소 어디에도
> **절대** 넣지 않습니다. `.env`는 git-ignore 되고, `node check.mjs`가 소스에서 실제 키
> 형식을 검사해 커밋되면 실패시킵니다.
